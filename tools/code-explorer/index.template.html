Come leggere la mappa

Selezione: le linee collegate rimangono in evidenza. Il passaggio del puntatore o del focus anticipa i collegamenti; la spiegazione cambia soltanto con la selezione.

  • Import: il sorgente importa un modulo.
  • Chiamata: invoca un metodo nominato.
  • Composizione: l’host collega una funzione o un servizio.
  • Contratto: due estremi usano lo stesso schema di messaggio.
  • HTTP: il browser prepara una richiesta alla route.

Direzione: dall’elemento che usa o collega a quello usato. La stessa linea non prova esecuzione, autorizzazione o raggiungibilità. Un collegamento assente non dimostra isolamento.

Come leggere i collegamenti tra file

La selezione di un modulo mostra i file citati come prove dei suoi elementi e collegamenti. I tratteggi grigi collegano il modulo a queste prove.

Le linee blu tra file rappresentano import o re-export statici; il tratteggio blu indica dichiarazioni soltanto di tipi. Una coppia può avere più dichiarazioni, conservate nella spiegazione.

Direzione: dal file che contiene la dichiarazione al file citato. La spiegazione distingue le dichiarazioni in uscita dalle citazioni ricevute.

Queste linee hanno un significato diverso dalle relazioni tra moduli. Non provano chiamate, esecuzione, autorizzazione o passaggio di dati. I file non collegati nella selezione possono avere altre dipendenze.

File e dichiarazioni

L’elenco conserva tutte le dichiarazioni dei file mostrati, anche quelle escluse dal diagramma dai filtri. Le fonti restano consultabili senza JavaScript.

Copertura ed esclusioni dei file

La selezione comprende soltanto l’unione dei file citati dai 15 moduli e dalle loro relazioni. I target fuori selezione sono collegati al sorgente, ma non vengono analizzati a loro volta. Non è una misura della copertura dei test o del prodotto.

L’extractor usa l’AST TypeScript e il resolver con l’albero Git e il tsconfig fissati al pin. Non legge i target dalla checkout corrente o dai pacchetti installati. I moduli Node e i pacchetti esterni rimangono distinti.

Import dinamici, chiamate denominate require e import come espressioni di tipo sono segnalati, ma esclusi dal grafo. Le forme calcolate non hanno un target attestato. Asset e linguaggi nativi non vengono analizzati. Non si deduce isolamento dall’assenza di una linea.

La fotografia dei file conserva dichiarazioni, righe, classificazione, esclusioni, hash e versione del parser. Schema dei dati.

Provenienza e limiti della fotografia

Quindici nodi scelti manualmente dal codice pubblico alla revisione indicata. Il generatore legge i file con Git, verifica gli ancoraggi e conserva hash dei file e dell’albero sorgente nel JSON della fotografia.

Un inventario dei file alla stessa revisione attesta soltanto la presenza dei file. Non prova import eseguiti, operazioni ammesse o correttezza delle protezioni. Questa pagina non contiene un modello AI e non è collegata a una cartella.
