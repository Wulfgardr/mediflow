Identità concessa

L'agente non usa né il token API né la sessione dell'operatore: riceve un'identità dedicata, revocabile in un comando.

Lease contestuale

Ogni lavoro vive dentro un lease a tempo, ancorato a un paziente. Il banner resta visibile per tutta la sessione.

Delta prima dei conteggi

L'output dice cosa è cambiato (+1 dall'ultima lettura), non solo quante voci ci sono.

Zero PHI nel canale debole

Riferimenti e iniziali nei comandi e negli elenchi; il dato pieno viaggia solo nell'artefatto richiesto esplicitamente.

Negato ≠ errore

Il diniego nomina il motivo esatto (denied_by_contract) e l'azione di recupero. Exit code distinti.

Artefatti a scope chiuso

Ciò che l'agente mostra all'operatore esiste dentro il lease: deep-link autenticato o HTML self-contained con watermark.
