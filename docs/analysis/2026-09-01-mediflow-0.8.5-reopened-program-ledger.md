## Scopo

Questo ledger coordina la riapertura governata definita da
[ADR 0110](../adr/0110-riapertura-governata-programma-intelligente-085.md).
Registra ownership, dipendenze, prove richieste e stop rule delle lane; non
sostituisce ADR, issue, test receipt o verbale finale.

Linear non può accettare nuove issue perché il workspace ha raggiunto il limite
del piano. GitHub è quindi il tracker operativo di questo programma. Le issue
WUL esistenti restano riferimenti storici e `WUL-564` resta il verificatore
terminale, ma non descrivono da sole il nuovo perimetro.

## Routing card P0 — governance comune

- Outcome: congelare confini, ADR number allocation e contratti di test prima
  del runtime.
- Scrittura autorizzata: ADR e documenti di coordinamento soltanto.
- Verifica: `git diff --check`, indice Markdown e `npm run check:claims`.
- Stop rule: nessuna lane può presentarsi come consegnata senza una receipt
  legata allo SHA integrato.

Numeri ADR riservati:

- `0111`: DeepSeek-OCR 2 selettivo;
- `0112`: provider v2, secret broker ed egress;
- `0113`: recording visita e trascrizione locale;
- `0114`: isolamento Intelligent Host, AIP e MCP.

I worker possono creare il proprio ADR ma non modificano gli indici condivisi;
l'integration manager li riallinea dopo l'integrazione.

## Routing card F6 — DeepSeek-OCR 2

- Worktree: `085-rush/278-ocr`.
- Outcome: OCR solo sulle pagine classificate `needsOcr`, con runtime locale
  esplicito e nessun fallback silenzioso.
- Prima prova: contratto TDD del router e classificazione di failure del runtime.
- Evidenza minima: fixture sintetiche, receipt per pagina, timeout/cancel e
  benchmark su corpus sintetico versionato.
- Stop rule: HOLD se il runtime ufficiale non è eseguibile sull'hardware
  disponibile o se input/output non restano local-only.

## Routing card F7 — provider ufficiali

- Worktree: `085-rush/279-provider`.
- Outcome: un provider v2 governato, adapter OpenAI e Anthropic disattivati per
  default, segreti fuori dal database clinico e provenance derivata
  dall'operazione realmente eseguita.
- Prima prova: lifecycle del secret reference e policy egress/retention
  fail-closed.
- Evidenza minima: unit test con transport fake, redaction dei log e contract
  test ufficiali senza chiamate live obbligatorie.
- Stop rule: nessuna chiave in Git, database, receipt, log o payload clinico;
  nessun claim zero-retention senza prova dell'account/progetto.

## Routing card F8 — recording visita

- Worktree: `085-rush/280-recording`.
- Outcome: consenso esplicito, registrazione controllata, audio effimero per
  default, trascrizione locale e bozza sempre review-only.
- Prima prova: state machine e permission boundary su API Apple correnti.
- Evidenza minima: test unitari, build host e test nativo su hardware o
  simulatore disponibile.
- Stop rule: HOLD su consenso ambiguo, persistenza audio implicita, background
  capture o fallback cloud.

## Routing card G0/F9 — Intelligent Host e MCP

- Worktree: `085-rush/285-security` per ADR/threat model; implementazione MCP in
  worktree separato dopo approvazione del boundary.
- Outcome iniziale: processo OS separato, locale, MCP stdio modern-only e un
  tool di stato non-PHI; nessun accesso diretto a Web auth o database.
- Prima prova: discover/list/call su processo reale e guard statico degli import.
- Evoluzione: broker AIP host-owned con lease opaco, currentness, revoca e audit
  minimizzato prima di qualunque dato clinico.
- Stop rule: nessun listener o egress, nessuna identità caller-supplied come
  autorità, nessuna serializzazione delle proof SOAP process-local.

## Protocollo di integrazione

1. Ogni lane parte dal medesimo SHA e produce commit piccoli per un solo confine.
2. Il writer consegna SHA, scope, test eseguiti, residui e claim ceiling.
3. L'integration manager verifica localmente prima di integrare; il report del
   worker non è prova finale.
4. Dopo ogni wave si controllano diff, attribuzione Codex, privacy, dipendenze e
   documentazione canonica.
5. Security review, suite finale, refacing e pubblicazione usano l'esatto SHA
   candidato e restano autorizzazioni separate.
