Quando una modifica è davvero registrata

Il browser e il server procedono separatamente. Interrompere l’attesa nel browser può lasciare una modifica ancora in corso sul server.

Ciò che vede il medico

Ciò che può fare il server

    Tracce semantiche sintetiche, curate dal modello TLC e dai test del controller/HTTP. Il caso difettoso è un controllo negativo, non il comportamento attuale. Limite: stesso profilo, origine e archivio con storage integro. Un esito ignoto può restare bloccato indefinitamente. Questa verifica finita non qualifica l’intera applicazione né l’uso clinico.
